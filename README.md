# Pulse 响应式数据看板

直接双击 index.html 即可运行，无需安装依赖，无需网络。

## 文件
- index.html：页面结构
- styles.css：响应式布局与两套主题
- app.js：6 张指标卡的数据、渲染、周期切换、图表及主题逻辑
- PROMPT.md：实现本作业的 prompt

## 对照截图要求
1. 小于 768px 单列；768–1199px 两列；1200px 及以上四列，第一卡跨两行、最后一卡跨两列。
2. 卡片采用 CSS Grid 和 minmax(0, 1fr)，没有固定页面宽度。
3. 使用弹性宽度、min-width:0 和可换行数字；目标宽度 320–1920px。
4. 6 张卡片来自 app.js 的 metrics 数组，通过 map 渲染。
5. 指标数字使用 font-variant-numeric: tabular-nums。
6. CSS 变量定义主题；原生 button 切换主题，localStorage 可用时记忆选择。
7. 无外部图片依赖；图标采用内联 SVG + currentColor；图表 SVG 随容器缩放。
8. 页面有 h1，卡片使用 section 和 h2，操作使用原生 button，筛选提供 aria-pressed。

所有数值为演示数据。周期切换会调整总量和趋势；比率、同比变化和渠道比例用于演示而保持固定，不连接业务后台。

## 验收建议
分别在 320、375、767、768、1024、1199、1200、1440、1920px 查看布局；在控制台检查 document.documentElement.scrollWidth <= window.innerWidth。点击三个周期并切换主题，检查数字、图表和按钮选中状态。用 Tab 检查焦点，再用 Enter/空格操作按钮。
